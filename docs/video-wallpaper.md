# Ручные видеообои

Waybar содержит отдельную play/pause-кнопку для `nv-wallpaper`. Это только
ручное управление: нет автозапуска, проверки активного окна и фонового policy.
Статичный `awww` остаётся на слое `BACKGROUND`, а видео появляется над ним
только после клика.

## Установка рендерера

Сам C++-рендерер остаётся отдельным репозиторием и не клонируется dotfiles.
`restore-config.sh` ставит его сборочные зависимости. При checkout в
`~/nv-wallpaper` установка выполняется от обычного пользователя:

```bash
cd ~/nv-wallpaper
./scripts/install-user.sh /absolute/path/to/video.mov DP-2,DP-3
```

После этого `~/.local/bin/nv-wallpaperctl` управляет user-systemd target.
Если бинарник отсутствует, кнопка показывает уведомление и ничего не запускает.

## Поведение кнопки

- play запускает `nv-wallpaper.target`;
- pause полностью останавливает renderer, освобождает GPU и показывает `awww`;
- последний реально показанный PTS сохраняется в XDG state, поэтому следующий
  play продолжает с прежней позиции;
- `wall-next.sh` и `wall-select.sh` сначала выключают видео, затем меняют
  статичную картинку;
- при завершении Hyprland target корректно останавливается.

Статусная иконка обновляется сигналом `RTMIN+11` сразу после клика и раз в пять
секунд как страховка. `video-wallpaper-icon.sh` окрашивает Lucide play/pause в
актуальный light/dark accent без зависимости от остального набора SVG Waybar.
