# docs — грабли и замечания

Сюда складываются вещи, на которые уже наступили один раз и не хотят наступать
второй: неочевидное поведение инструментов, флаги, которых нет, ограничения,
которые нельзя обойти, и решения, у которых была неочевидная причина.

Правило одно: **каждая запись объясняет «почему», а не только «как»**. Запись без
причины через полгода выглядит как случайная строка в конфиге, и её удаляют.
