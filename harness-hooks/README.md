# Шаблон hooks для индикатора агентов в tmux

Каталог намеренно не содержит vendor-specific фрагментов. Набор харнессов
меняется локально и не является частью dotfiles.

Если локальный клиент умеет сообщать состояния, его hooks должны обновлять
переменные tmux, которые читает `~/.config/tmux/agent-win.sh`. Имена процессов
и иконки задаются локально через `@agent-indicator-processes` и
`@agent-indicator-icons`; в версионируемом `.tmux.conf` список пуст.

Не добавляй сюда токены, runtime-сессии или полные vendor-конфиги. Общий
фрагмент стоит версионировать только если он не зависит от конкретного клиента.
