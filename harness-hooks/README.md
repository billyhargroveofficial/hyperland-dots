# Индикатор Codex в tmux

Для tmux-индикатора в `.tmux.conf` задан только процесс `codex` и иконка `🧠`.
`~/.config/tmux/agent-win.sh` ищет полную командную строку на tty, поэтому
запасной детект видит и node-обёртку Codex. OpenCode при этом остаётся
поддерживаемым CLI, просто его состояние в панель tmux сейчас не выведено.

Состояния `running` / `needs-input` / `done` приходят из нативных локальных hooks
Codex. Они обновляют переменные tmux, которые читает `agent-win.sh`; пока
состояния нет, вкладка показывает серый запасной индикатор процесса.

Сами hooks, токены, runtime-сессии и содержимое `~/.codex/` сюда не копируются:
это приватное нативное состояние, а не dotfiles.
