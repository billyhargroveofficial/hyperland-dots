# Шаблон AI control plane

Этот каталог — нейтральная стартовая заготовка для локального
`~/.config/agents/`. Он намеренно не содержит списка установленных харнессов,
их количества, vendor-настроек, MCP-сервисов или секретов.

Актуальная конфигурация живёт только на конкретной машине. После первого
копирования она может свободно меняться и не обязана совпадать с dotfiles.

## Состав шаблона

- `.rulesync/rules/` — общие правила;
- `.rulesync/mcp.jsonc` — пустая заготовка MCP;
- `.rulesync/skills/` — каталог общих skills;
- `rulesync.jsonc` — пустой объект `targets`;
- `secrets.env.example` — безымянная заготовка локального окружения;
- `mcp-sync` — нейтральная обёртка над `rulesync generate`.

## Инициализация

```bash
cd ~/hyperland-dots
./scripts/install-ai-harnesses.sh
```

Bootstrap устанавливает Rulesync при необходимости и копирует только
отсутствующие файлы. Существующие `~/.config/agents`, `~/.local/bin/mcp-sync`,
конфиги клиентов и runtime-состояние он не перезаписывает и не удаляет.

После инициализации настрой локальные targets, MCP и секреты, затем выполни:

```bash
mcp-sync --list-targets
mcp-sync --dry-run
mcp-sync
mcp-sync --check
```

Пустой список targets в репозитории — штатное состояние, а не ошибка.

## Что не хранится в dotfiles

- фактический перечень установленных харнессов;
- vendor-конфиги и target-specific обходы несовместимостей;
- MCP-серверы, фоновые сервисы и их версии;
- токены, OAuth-кэши, сессии, история и runtime-memory;
- локальная курируемая память из `~/.agents/memory/`.

Если локальному клиенту нужен особый post-processing, держи его рядом с
локальным control plane. Универсальную логику можно вернуть в шаблон только
когда она не зависит от имени, количества или формата конкретных харнессов.
